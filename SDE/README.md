# System Design Exercise: A Complete Sensing and Navigation System

Design a complete robotic sensing and navigation system for one application scenario, on paper and on your own: requirements, architecture, sensors, localization, integration, and failure analysis. Then present it in five slides and five minutes, as a warm up for the final project.

Start with Part 0 of the instructions notebook.

## Files in this folder

| File | What it is |
|---|---|
| `EECE5554_SDE_instructions.ipynb` | The instructions and the design tools in one notebook: the method, the scenarios, Parts 1 to 6 with eleven tools, the report and the talk, the rules for AI tools, and the assessment |
| `EECE5554_SDE_example.md` | A complete worked example, a robotic lawn mower, whose numbers fill the notebook's tools |
| `EECE5554_SDE_report_template.md` | The report skeleton, with every required heading and table |
